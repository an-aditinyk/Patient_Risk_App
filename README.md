# HospitAI: Clinical Readmission Risk Suite

A machine learning solution to identify high-risk hospital discharges and prevent the $26 Billion readmission "leak."

### Key Features
* **AI Engine:** Balanced Random Forest model using SMOTE & Under-sampling.
* **Clinical Console:** Streamlit UI for real-time patient risk scoring.
* **Executive Analytics:** Interactive ROI dashboard using Plotly.
* **Feature Engineering:** Custom 'Medical Intensity Score' to track care complexity.

### Tech Stack
* **Language:** Python 3.12
* **Libraries:** Scikit-Learn, Pandas, Streamlit, Plotly, Joblib
* **Deployment:** GitHub & Streamlit Cloudgit init
